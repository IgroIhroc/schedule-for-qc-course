# Чеклісти для тестування

## Модуль: Додавання пари в розклад (адмін-панель)

### Функціональність

- [ ] Відкривається форма додавання нової пари
- [ ] Можна вибрати групу
- [ ] Відображається список доступних груп
- [ ] Можна вибрати день тижня
- [ ] Можна вибрати часовий слот
- [ ] Відображаються доступні слоти
- [ ] Заблоковані зайняті слоти
- [ ] Можна вибрати аудиторію
- [ ] Відображається список аудиторій
- [ ] Заблоковані зайняті аудиторії
- [ ] Можна вказати предмет
- [ ] Можна вказати викладача
- [ ] Можна зберегти створену пару
- [ ] Після збереження пара з’являється в розкладі
- [ ] Дані коректно оновлюються після створення

---

### Негативні сценарії

- [ ] Спроба зберегти пару без вибору групи
- [ ] Спроба зберегти пару без вибору часу
- [ ] Спроба зберегти пару без вибору аудиторії
- [ ] Вибір уже зайнятого часового слоту
- [ ] Вибір уже зайнятої аудиторії
- [ ] Швидке повторне натискання кнопки "Зберегти"
- [ ] Введення некоректних або порожніх даних
- [ ] Скасування створення пари без збереження

---

### UI/UX

- [ ] Форма коректно відображається на екрані
- [ ] Поля не накладаються одне на одне
- [ ] Помилки відображаються зрозуміло
- [ ] Кнопки активні/неактивні коректно
- [ ] Інтерфейс не зависає при виборі значень
- [ ] Список слів/аудиторій читається нормально
- [ ] Після створення пари немає дублювання UI елементів
