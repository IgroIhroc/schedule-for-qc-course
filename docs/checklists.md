# Чеклісти для тестування

## Модуль: Перегляд розкладу викладача

### Функціональність

- [ ] Відображається список викладачів
- [ ] Пошук знаходить існуючого викладача
- [ ] Відображається розклад вибраного викладача
- [ ] Показуються всі дні тижня
- [ ] Відображається час занять
- [ ] Відображається назва предмету
- [ ] Відображається група
- [ ] Відображається аудиторія
- [ ] Відображається тип заняття
- [ ] Коректно працює перемикання тижнів

### Негативні сценарії

- [ ] Пошук неіснуючого викладача
- [ ] Пошук порожнім рядком
- [ ] Введення спеціальних символів у пошук
- [ ] Введення дуже довгого тексту
- [ ] Швидке перемикання між тижнями

### UI/UX

- [ ] Текст не накладається
- [ ] Розклад коректно відображається на малому екрані
- [ ] Кнопки перемикання тижнів помітні
- [ ] Інтерфейс не зависає
- [ ] Всі елементи читабельні
